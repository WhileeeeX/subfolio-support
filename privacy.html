隐私政策

适用范围

更新日期：2026年11月15日。Subfolio 由独立开发者 CHENG ZHONG 提供。本政策说明 App 和本支持网站如何处理信息。联系邮箱：applesandbox.zc@gmail.com。

本机数据

订阅、金额、商家、消费日期、付款方式、备注、头像、名字、签名及偏好设置用于提供订阅管理、记账、分析和提醒，默认保存在设备上。无需注册 Subfolio 账号。当前版本没有接入广告或第三方行为分析 SDK，也不出售个人信息。

照片、相机和识别

只有在你选择照片或使用拍照功能时处理相关图像。票据文字识别通过 Apple Vision 在设备上完成，不向开发者服务器或第三方 AI 服务发送票据图片。你确认保存后，识别出的文字作为流水记录保存。选作头像的照片会保存为个人资料的一部分。你可在系统设置中管理相机权限。

可选 iCloud 同步

开启同步后，订阅、流水、主要卡片选择及个人资料和部分偏好会通过 Apple CloudKit 存储到你的 iCloud 私有数据库，用于设备间同步。开发者不运营用于保存这些记录的自有服务器。关闭同步停止后续同步，但不会自动删除已有云端数据。Apple 按其隐私政策处理 iCloud 服务数据。

购买、提醒和汇率

购买通过 Apple App Store 处理，App 使用交易及权益状态判断 Pro 权限；开发者不会收到你的银行卡信息。提醒使用本地通知，需要你的授权。换算货币时访问 Frankfurter 汇率服务，请求包含币种代码，不包含你的账目、金额或备注；网络服务可能接收 IP 地址等必要连接信息。

保存、删除和导出

本地记录保留至你删除；会员到期不会删除已有记录。可在 App 内删除订阅和流水，并在个人设置中导出数据。开启同步时，记录删除会在成功同步后传递到其他设备。卸载 App 不等于删除 iCloud 或设备备份中的数据；云端及备份数据请通过 Apple 提供的 iCloud 存储管理功能管理，或联系我们获取操作指导。自行导出的文件由你保管并删除。开发者无法代你直接读取或删除 iCloud 私有数据库。

邮件与本网站

联系支持时，我们会收到你的邮箱和自愿提供的内容，仅用于处理反馈与支持；不再需要时删除，法律要求保留的除外。你可以来信请求访问、更正或删除支持邮件中的个人信息。不要发送密码、验证码或完整支付凭证。本网站没有添加广告、分析脚本或追踪 Cookie；托管方 GitHub Pages 会为安全目的记录访问 IP 地址。

你的选择与政策更新

你可以关闭 iCloud 同步、撤销通知或相机权限，修改或删除记录。我们仅为所述功能和你的选择处理信息；必要时依据适用法律处理支持请求。服务商可能在不同地区处理服务数据，受其条款及适用法律约束。功能或处理方式变化时会更新本政策和日期；需要额外授权时会另行征求。

应用搜索与图标下载

在添加订阅时输入关键词，App 会向 Apple 的应用搜索服务（itunes.apple.com）发送搜索词和设备地区对应的商店地区代码，以查找应用名称、分类和图标。搜索会在输入后自动发起，不需要另点搜索按钮；请勿在搜索框输入敏感个人信息。图标会从搜索结果提供的图片地址下载。上述网络服务会接收请求所需的 IP 地址等连接信息，并按服务提供方的政策处理。我们不运营用于记录搜索词的自有服务器。搜索不会读取你的 Apple 账户订阅、购买历史或其他 App 内的账户资料。

自定义订阅图标与颜色

你可以选择系统符号、背景颜色或通过系统照片选择器选取图片。App 仅使用你选中的图片，不需要浏览整个照片图库；图标图片和样式随订阅记录保存在设备上，开启 iCloud 同步后随相关记录同步。恢复默认图标所需的原始图片也可能随记录保存。自定义图标不会上传到搜索服务。小组件和实时活动可通过设备上的共享容器读取显示所需的数据与图标；请留意锁屏上可能显示的订阅名称和金额。

删除全部数据与系统分享

个人设置中的“还原 → 删除全部数据”需再次确认，会清空本机订阅、流水和主要卡片选择，重置个人资料与记账货币，并关闭续费提醒；不会取消 Apple 管理的 Pro 购买或商家的实际订阅。App 保存删除状态；启用 iCloud 且成功完成后续同步后，该删除状态会同步到云端及其他设备。离线或同步关闭时，云端删除不会立即完成。自行导出的文件、系统备份及已发送给他人的内容不受此操作影响。“推荐给朋友”打开系统分享面板，由你选择接收方和分享方式；分享应用链接不会自动附带订阅或流水记录。

备份文件与恢复

手动导出生成 JSON 文件，包含订阅、流水、主要卡片选择，以及名字、头像、签名、外观、卡片显示、提醒开关、记账货币、汇率日期和语言等备份设置。订阅内保存的图标图片、颜色和恢复默认所需的图片数据也可能包含在文件中。文件通过系统文件界面保存到你选择的位置，App 不为导出的 JSON 添加密码保护。请勿将备份公开上传或发送给不信任的人。使用第三方存储或传送文件时，对方按自己的条款处理。导入经确认后会替换相应记录及设置；旧版不含流水的备份会保留当前流水。开启 iCloud 时，导入后的更改也可同步到其他设备。

搜索结果的保存与本地缓存

搜索结果用于当前搜索界面，App 不提供持久化搜索历史。选中联网结果并保存订阅时，当前实现保存应用名称、映射后的分类和下载的图标图片，不把开发者名称、商店链接或远程图片地址作为该订阅的独立字段保存。图标图片属于订阅记录的一部分，可随记录备份和 iCloud 同步。设备上还可能保留汇率缓存、小组件显示快照和实时活动图标文件。删除记录会更新相关显示数据，但不代表所有独立缓存、系统快照或备份副本被立即物理清除；图标更换后，为恢复默认而保留的数据也可能继续存在于记录中。

系统权限与显示内容

拍照扫描使用相机权限；选择票据、头像或订阅图标使用系统照片选择器，仅获取你选中的内容。App 不需要完整照片图库访问权限。续费提醒使用通知权限，在设备本地安排，通知可能包含订阅名称、预计金额和提前提醒信息。你可以在系统设置中管理相机、通知及锁屏预览；拒绝权限将影响对应功能，不会因此删除已有记录。当前应用未接入广告追踪功能，也不为这些功能请求位置、通讯录、麦克风或系统日历权限。

外部服务与信息接收方

Apple App Store / StoreKit：处理购买、恢复购买和权益验证。Apple iCloud / CloudKit：在启用同步后处理相关记录与图片。Apple 应用搜索及图片服务：接收搜索词、商店地区与必要请求参数，并提供搜索结果及图片。Frankfurter：接收用于查询参考汇率的币种代码。GitHub Pages：托管本网站，按 GitHub 政策处理网站访问日志。邮件、文件或分享服务：仅在你主动使用时接收你选择发送或保存的内容。当前应用没有集成 RevenueCat、Mixpanel、广告 SDK 或第三方行为分析 SDK。上述网络服务可能接收 IP 地址等必要连接信息。

数据安全与跨地区处理

我们尽量减少不必要的传输，通过 HTTPS 请求应用搜索、图标和汇率服务，并使用 Apple 提供的设备及 iCloud 机制。实际存储和处理地区由相应服务及账户安排决定；我们不承诺全部数据只存放在某个国家或地区，也不将所有存储方式统称为端到端加密。任何设备、存储或传输方式都无法保证绝对安全。请保护设备解锁凭证、Apple 账户及备份文件，并及时更新系统。

隐私请求与儿童信息

你可以在 App 内查看、修改、删除和导出记录，并管理同步与系统权限。根据适用法律，你还可能享有访问、更正、删除、限制处理、反对处理或数据可携带等权利。对开发者实际持有的支持邮件及其附件，可通过本页邮箱提出请求；我们会在适用法律要求的期限内处理，并仅在必要时核实请求。仅保存在你的设备、私人 iCloud 或自行选择的服务中的数据，需要由你通过相应功能管理。Subfolio 是通用订阅与支出管理工具，不专门面向儿童，也不主动要求儿童提供身份资料。若监护人认为支持沟通中提交了儿童个人信息，可联系我们核查并按适用要求处理。

外部链接与重要变更通知

本页面及 App 可能打开 Apple 条款、隐私政策或其他外部服务。对方的信息处理适用其自己的政策。我们会在功能、服务或数据处理方式发生变化时更新本政策与日期；对重大变化，通过适当的应用提示或其他合理方式告知，依法需要额外授权时另行征求。隐私咨询请联系 CHENG ZHONG：applesandbox.zc@gmail.com。

隱私政策

適用範圍

更新日期：2026年11月15日。Subfolio 由獨立開發者 CHENG ZHONG 提供。本政策說明 App 與本支援網站如何處理資訊。聯絡信箱：applesandbox.zc@gmail.com。

裝置資料

訂閱、金額、商家、消費日期、付款方式、備註、頭像、名字、簽名及偏好用於訂閱管理、記帳、分析與提醒，預設儲存在裝置上。無需註冊 Subfolio 帳號。目前版本沒有廣告或第三方行為分析 SDK，也不出售個人資訊。

照片、相機與辨識

僅在你選取照片或拍照時處理相關影像。收據辨識透過 Apple Vision 在裝置上完成，不將收據圖片傳送至開發者伺服器或第三方 AI 服務。確認儲存後，辨識文字作為流水紀錄保存。頭像照片作為個人資料保存。相機權限可在系統設定管理。

可選 iCloud 同步

開啟後，訂閱、流水、主要卡片選擇、個人資料及部分偏好透過 Apple CloudKit 存入你的 iCloud 私有資料庫，用於跨裝置同步。開發者沒有用於儲存這些紀錄的自有伺服器。關閉同步不會自動刪除既有雲端資料。Apple 依其隱私政策處理 iCloud 服務資料。

購買、提醒與匯率

Apple App Store 處理購買；App 使用交易及權益狀態判斷 Pro 權限，開發者不會收到銀行卡資訊。提醒為需授權的本機通知。換算貨幣時向 Frankfurter 傳送幣別代碼，不傳送帳目、金額或備註；服務可能收到 IP 位址等連線資訊。

保存、刪除與匯出

本機紀錄保留至你刪除；會員到期不刪除資料。可在 App 刪除訂閱和流水，並在個人設定匯出資料。開啟同步時，刪除會於成功同步後傳至其他裝置。移除 App 不等於刪除 iCloud 或備份資料；請透過 Apple 的 iCloud 儲存空間管理功能管理，或聯絡我們取得操作協助。自行匯出的檔案由你保管與刪除。開發者無法直接讀取或刪除你的 iCloud 私有資料庫。

郵件與本網站

聯絡支援時，我們收到你的信箱與自願提供的內容，僅用於回覆與支援；不再需要時刪除，法律要求保留者除外。可來信請求存取、更正或刪除支援郵件中的個人資訊。請勿寄送密碼、驗證碼或完整付款憑證。本站沒有廣告、分析腳本或追蹤 Cookie；GitHub Pages 會為安全目的記錄訪客 IP 位址。

選擇與政策更新

你可關閉同步、撤銷通知或相機權限，修改或刪除紀錄。我們僅為所述功能及你的選擇處理資訊，必要時依適用法律處理支援請求。服務商可能在不同地區處理資料，受其條款及適用法律約束。功能或處理方式變更時會更新政策與日期；需要額外授權時另行徵求。

應用程式搜尋與圖示下載

在新增訂閱時輸入關鍵字，App 會向 Apple 的應用程式搜尋服務（itunes.apple.com）傳送搜尋詞與裝置地區對應的商店地區代碼，以尋找名稱、分類和圖示。輸入後會自動搜尋，無需另按搜尋按鈕；請勿在搜尋欄輸入敏感個人資訊。圖示會從搜尋結果提供的圖片網址下載。上述網路服務會接收請求所需的 IP 位址等連線資訊，並依服務提供者的政策處理。我們沒有用於記錄搜尋詞的自有伺服器。搜尋不會讀取你的 Apple 帳號訂閱、購買紀錄或其他 App 的帳號資料。

自訂訂閱圖示與顏色

你可以選擇系統符號、背景顏色，或透過系統照片選擇器選取圖片。App 僅使用你選取的圖片，無需瀏覽整個照片圖庫；圖片與樣式隨訂閱紀錄儲存在裝置上，開啟 iCloud 後隨相關紀錄同步。恢復預設圖示所需的原始圖片也可能隨紀錄保存。自訂圖示不會上傳至搜尋服務。小工具與即時動態可透過裝置上的共享容器讀取顯示所需的資料與圖示；請留意鎖定畫面可能顯示的訂閱名稱及金額。

刪除全部資料與系統分享

個人設定中的「還原 → 刪除全部資料」需要再次確認，會清空本機訂閱、流水及主要卡片選擇，重設個人資料與記帳貨幣，並關閉續費提醒；不會取消 Apple 管理的 Pro 購買或商家的實際訂閱。App 會保存刪除狀態；啟用 iCloud 且成功完成後續同步後，刪除狀態會同步至雲端及其他裝置。離線或同步關閉時，雲端刪除不會立即完成。自行匯出的檔案、系統備份與已分享給他人的內容不受影響。「推薦給朋友」開啟系統分享面板，由你選擇接收者與分享方式；分享應用程式連結不會自動附上訂閱或流水紀錄。

備份檔案與還原

手動匯出會產生 JSON 檔案，包含訂閱、流水、主要卡片選擇，以及名字、頭像、簽名、外觀、卡片顯示、提醒開關、記帳貨幣、匯率日期與語言等備份設定。訂閱中儲存的圖示圖片、顏色及恢復預設所需的圖片資料也可能包含其中。檔案透過系統檔案介面存至你選擇的位置；App 不為匯出的 JSON 加上密碼保護。請勿公開上傳備份或寄給不信任的人。使用第三方儲存或傳送服務時，對方依其條款處理。確認匯入後會取代對應紀錄與設定；不含流水的舊版備份會保留目前流水。開啟 iCloud 時，匯入後的變更也可同步至其他裝置。

搜尋結果保存與本機快取

搜尋結果用於目前搜尋介面，App 不提供持久化搜尋歷史。選取聯網結果並儲存訂閱時，目前實作保存應用程式名稱、對應分類和下載的圖示圖片，不將開發者名稱、商店連結或遠端圖片網址作為該訂閱的獨立欄位保存。圖示圖片屬於訂閱紀錄的一部分，可隨紀錄備份及 iCloud 同步。裝置也可能保留匯率快取、小工具顯示快照和即時動態圖示檔案。刪除紀錄會更新相關顯示資料，但不代表所有獨立快取、系統快照或備份副本會立即被實體清除；更換圖示後，為恢復預設而保留的資料也可能繼續存在於紀錄中。

系統權限與顯示內容

拍照掃描使用相機權限；選取收據、頭像或訂閱圖示使用系統照片選擇器，只取得你選取的內容，無需完整照片圖庫存取權。續費提醒使用通知權限，在裝置本機安排；通知可能包含訂閱名稱、預計金額及提前提醒資訊。可在系統設定管理相機、通知與鎖定畫面預覽；拒絕權限會影響對應功能，不會因此刪除既有紀錄。目前 App 未整合廣告追蹤，也不為這些功能要求位置、聯絡人、麥克風或系統行事曆權限。

外部服務與資訊接收者

Apple App Store / StoreKit：處理購買、恢復購買與權益驗證。Apple iCloud / CloudKit：啟用同步後處理相關紀錄與圖片。Apple 應用程式搜尋與圖片服務：接收搜尋詞、商店地區及必要參數，提供結果與圖片。Frankfurter：接收查詢參考匯率所需的幣別代碼。GitHub Pages：託管本網站，依 GitHub 政策處理存取紀錄。郵件、檔案或分享服務：僅在你主動使用時接收你選擇傳送或保存的內容。目前 App 未整合 RevenueCat、Mixpanel、廣告 SDK 或第三方行為分析 SDK。上述網路服務可能接收 IP 位址等必要連線資訊。
